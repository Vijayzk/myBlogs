# 🚀 Frontend Blog Application

A modern, responsive frontend web application built with React 19, Vite, TailwindCSS, and Redux Toolkit. Designed for high performance and rapid development with a smooth developer experience.

# 🧰 Tech Stack
React 19 – UI library for building interactive interfaces

Vite – Next-generation frontend tooling for lightning-fast builds

Tailwind CSS 4 – Utility-first CSS framework

DaisyUI – Component library for Tailwind CSS

Redux Toolkit – State management made simple

React Router v7 – Client-side routing

Framer Motion – Declarative animations

Axios – Promise-based HTTP client

Swiper – Modern touch slider

JS-Cookie – Cookie management utility

# 📦 Installation

git clone https://github.com/your-username/frontend.git

cd frontend

npm install

npm run dev

# 🧪 Linting

This project uses ESLint with React-specific rules to enforce consistent coding standards:

npm run lint

# 📝 Environment Variables
Create a .env file in the root directory and define your environment variables:


VITE_API_URL=https://your-api.com
